# Sources and licensing

This repository contains a snapshot of installed skill packages. Inclusion does not imply authorship or grant new redistribution rights.

| Collection | Source | Treatment |
| --- | --- | --- |
| Custom skills | Local Codex user skill directory | Original instructions and resources preserved |
| System skills | Local Codex built-in skill directory | Bundled license files retained where supplied |
| Plugin skills | Local `openai-curated-remote` cache | Package versions and shared resource layout preserved |

The [inventory](inventory.json) records each skill's source using portable labels rather than user-specific absolute paths. Plugin snapshots include Sites 0.1.75, Work Pets 0.1.6, Plugin Management 0.1.0, and OpenAI Templates 0.1.1.

Applicable license files remain next to their original content, including third-party licenses within templates. Where a package does not supply a license, this repository does not assign one or claim additional reuse rights. Consult the original provider's terms before redistributing or incorporating that content into another project.

No blanket license is applied to the mixed collection. Repository documentation and maintenance scripts do not override upstream package terms.
