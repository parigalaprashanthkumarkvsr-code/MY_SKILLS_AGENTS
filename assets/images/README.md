# Repository image assets

This directory contains artwork created for the repository documentation. The cover uses white and shades of blue and represents all six skill groups in the current inventory.

```text
generated/
  skills-overview-blue-white-v1.png
prompts/
  skills-overview-blue-white-v1.txt
  skills-overview-blue-white-v1-correction.txt
metadata.json
```

The overview was generated with the built-in imagegen tool on October 5, 2026, then edited to remove non-blue accents and application letter badges. Both prompts are retained. Counts describe skills and skill interface metadata, not running standalone agents.

This cover is conceptual artwork. The [skill catalog](../../docs/CATALOG.md) is the authoritative directory of skill names and instructions.

Existing upstream references, previews, and icons remain in their original skill or plugin assets directories. See the [image reference library](../../docs/IMAGES.md) for an organized index, and [source notes](../../THIRD_PARTY_NOTICES.md) for licensing context.
